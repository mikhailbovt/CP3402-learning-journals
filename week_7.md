## Learning Activities & Resources

In the past week, I have understood the concepts of server-side programming using.php code. I have taken a look at the lecture slides related to PHP of the 7th week and have designed my original two-page website known as After Hours Lab. The website helps to create a short study-session schedule based on the energy level chosen by the user and the time available. While designing the site, I practiced using echo command to create different types of HTML, if/else if/else statements to modify the output and for, while and foreach loops to create repeated content on the page using arrays.

Furthermore, I made some reusable functions taking parameters, and made one function for creating a personal focus message and another one for creating a task card. Lastly, I separated the common header and footer information into include files and included them on the two pages. I then launched the website using the local web server of PHP and verified all the php files for syntax.

## Content Insights

This week, I learned that PHP creates the final HTML on the server first, prior to the user accessing the web page through their browser. Therefore, making PHP decisions and using loops brings data into visible page content. Also, I found out that when arrays and foreach are used together, the data needs to be created only once and can be displayed more than once even with the use of foreach, increasing usability and efficiency of data processing. I also found that functions help to eliminate duplicate lines of code and that using the same file for common components throughout the pages of a site allows you to manage the site more easily.

## Career/Employability/Learning Insights

The practical illustrated the piece-by-piece coming together of programming elements into functional web page. Splitting the process into layout, reusable functions, page-specific logic, and style follows the same principles as in larger web-based projects. Testing syntax and making sure every input path is checked also proved that coding is not just writing but also making sure it works.
